> 一款利用手机摄像头识别姿态、与郊狼设备联动的 Android 应用。支持本地虚拟调试，视频遮脸仍为实验功能；欢迎在 Issues 中反馈问题与建议。

**把手机架好，让猫娘教官看着小公主站稳、收好双手，再完成不定时的屈膝礼考核。** 动作幅度、输出强度、波形和游戏时长，都由你自己设置。

安装需要 **Android 8.0 及以上**；当前提供开发签名 APK。下载 APK 后，按手机提示允许本次安装即可。

## 这是什么

CoyoteVision 把安卓手机变成一位观察站姿的“猫娘教官”：摄像头持续跟踪手腕、腿脚和躯干，按校准后的动作幅度调整输出，也可以加入随机屈膝礼任务与忍耐训练。

**一部手机负责看动作，另一部手机负责连接设备。** 姿态手机运行本应用；设备手机运行 DGLAB 4 官方 App，通过蓝牙连接郊狼 2.0 或 3.0。两部手机在局域网中配对，日常游玩无需电脑或 Mac。

没有设备也可以先玩：选择 **虚拟输出调试**，就能查看动作识别、阶段提示与模拟强度，不向设备输出。

## 能做什么

| 功能 | 体验 |
| --- | --- |
| **站姿与动作监测** | 记录自己的站姿和手位，持续跟踪手、脚、躯干及整体离位 |
| **自定义强度映射** | 分别设置动作的最高强度，以及多大动作幅度达到最高值 |
| **随机屈膝礼** | 三连提示后，在期限内完成校准过的屈膝礼并保持指定时间 |
| **忍耐训练** | 随机进入训练阶段，使用独立基础强度，继续监测动作违规 |
| **波形选择** | 常态、提示、行礼过程、惩罚和训练分别配置通道与波形 |
| **统一游戏时间** | 一轮 1–90 分钟，各玩法共用总时长；人物丢失时暂停等待恢复 |
| **虚拟输出与控制台** | 不连接设备也能调试，查看手脚变化、输出强度和必要日志 |
| **镜子模式与隐藏骨架** | 可只保留视频及颜色提醒，也可独立隐藏骨架并保留控制界面 |
| **实验性视频遮脸** | 用白色椭圆覆盖眼鼻口，支持整体大小、宽高和位置调整 |
| **设置代码** | 一键复制或导入参数，方便保存配置、在手机之间迁移 |

参数说明收在标题旁的小问号里，想看时再点开喵。

## 需要准备什么

- **姿态手机**：一部 Android 8.0+ 手机，摄像头能拍到单人全身，摆放稳定。
- **设备手机**：另一部能运行 DGLAB 4 官方 App 的手机。
- **电击器**：一台郊狼 2.0 或 3.0，由官方 App 通过蓝牙连接。
- **网络**：两部手机连接允许设备互访的同一 Wi-Fi。

**只使用虚拟调试时，仅需姿态手机，不需要设备、配对或第二部手机。**

## 快速开始

### 1. 先试虚拟输出

打开应用，进入 **「05 养成模式」**，保留默认的「虚拟输出调试」。在 **「02 罚站规矩与电流」** 设置总时长、全局最高、常态及动作参数。

所有强度默认是 **0**。想查看模拟强度变化，需要自己填写相应数值；虚拟模式即使已经扫码配对，也不会向设备输出。

### 2. 需要设备联动时，再连接两部手机

1. 两部手机接入同一 Wi-Fi。
2. 在设备手机的 DGLAB 4 中，通过蓝牙连接 **一台** 郊狼 2.0 或 3.0。
3. 在姿态手机的 **「01 课前准备 · 两手机配对」** 中选择本机 Wi-Fi 地址，点击「开启两手机连接并显示配对码」。
4. 用设备手机的 DGLAB 4 **Socket 控制扫码入口**扫描这个二维码。
5. 等待姿态手机显示已配对及设备型号，再选择设备输出模式。

**扫码方向：本应用显示二维码 → 官方 App 扫描。** 重连后需重新扫码；官方 App 中请只保留一台连接的郊狼。

### 3. 开启摄像头，完成自己的姿态校准

点击首页的 **「开启摄像头」**，按提示授权；看到预览后，再点 **「开始罚站」**。此时退到合适位置，让全身入镜。

| 顺序 | 动作 | 用途 |
| --- | --- | --- |
| ① 确认位置 | 双臂向两侧平举，保持 **2 秒** | 确认本轮站立位置 |
| ② 记录屈膝礼 | 微屈膝、双手提裙摆姿势，保持 **3 秒有效画面** | 记录游戏要匹配的个人动作 |
| ③ 记录站姿 | 起身并拢双腿，双手放在自己选择的腹前位置，静止 **5 秒** | 记录站姿和手位基准 |

手位以你实际放下后静止的位置为准，不要求对准估算的肚脐。屈膝礼主要判断双手位置与髋部下沉；腿部点闪烁不会单独打断行礼保持。

**全部校准完成后，才开始总计时与当前模式的输出。** 校准期间不计游戏时间、不输出。

### 4. 按自己的规矩开始

- **普通罚站**：动作越接近所设满幅范围，目标越接近对应最高强度；多项动作同时发生时取较高结果，不重复相加。
- **屈膝礼任务**：先播放三连提示，再进入判定；保持达标即成功，之后给 **2 秒**调整回站姿。超时则播放所选惩罚波形，目标为「常态＋惩罚增量」，受总上限限制。
- **忍耐训练**：使用「训练基础＋动作违规升幅」，与屈膝礼任务不重叠。

本轮所有阶段共用总时长。人物主体丢失时暂停计时并请求停止输出，重新校准后继续剩余时间；进入后台或连接异常会结束本轮。

## 不用看文字，也能知道进行到哪一步

| 视频边框 | 含义 |
| --- | --- |
| 🟨 黄色三次闪烁 | 三连提示，准备行礼 |
| 🟦 蓝色与递减光带 | 正在判定屈膝礼 |
| 🟩 绿色 | 开始确认或行礼成功 |
| 🟥 红色 | 行礼超时，进入惩罚阶段 |
| 🟧 橙色闪烁 | 手脚大幅动作导致输出突增提醒 |

在 **「05 养成模式」** 中，可开启镜子模式：完成校准后隐藏控制界面，只保留视频、已开启的遮脸和颜色提醒。轻点画面可退出镜子模式；手机返回键可停止并返回设置。

**「隐藏骨架」是独立选项**：不开镜子模式也能隐藏骨架，控制台与按钮继续显示，遮脸和动捕不受影响。

## 保存一套自己的设置

在 **「05 养成模式」** 点击「导出全部设置代码」，将代码复制并保存；下次复制代码，点击「导入设置代码」即可恢复。没有剪贴板内容时，也可以手动粘贴。

代码包含游戏参数、模式、波形、通道与显示偏好，**不包含配对连接、人物坐标或本轮进度**。导入只恢复设置，不会开启摄像头、开始游戏或自动输出。

## 常见问题

<details>
<summary><b>没有电击器，可以测试吗？</b></summary>

可以。虚拟输出采用相同的动作识别与玩法流程，只在本机模拟。先用它查看校准、手脚分值、强度变化和任务提示即可。

</details>

<details>
<summary><b>显示有强度，设备却没有输出？</b></summary>

先确认当前选择的是设备输出模式，而非虚拟模式；再检查是否已配对、校准完成，且总上限及相关强度大于 0。另一部手机的官方 App 还需能正常控制设备，请同时检查它的静音、通道上限和设备连接。

控制台中的模拟值、本机计算值或已提交值不等于人体电流测量；官方 App 和设备状态也会影响实际输出。连接中断时，软件无法保证停止指令送达设备。

</details>

<details>
<summary><b>扫码连接不上怎么办？</b></summary>

确认两部手机处于允许设备互访的同一 Wi-Fi，姿态手机选择了正确的 Wi-Fi IPv4 地址。访客网络或设备隔离可能阻止连接。重新开启连接后，请用新二维码配对，并确认官方 App 中只有一台郊狼处于连接状态。

</details>

<details>
<summary><b>裙子遮住腿部，或者动作总是判不准？</b></summary>

固定手机，保持单人入镜，让手腕、肩髋和腿脚尽量清楚。屈膝礼主要参考本轮记录的双手和髋部，不要求腿部点始终稳定；普通罚站仍需要可靠的全身跟踪。可在设置中调整手腕靠近距离、屈膝礼范围、保持时间及动作满幅范围。

移动手机、切换镜头或明显改变拍摄距离后，请重新校准。

</details>

<details>
<summary><b>遮脸会影响识别吗？能保证完全遮住吗？</b></summary>

遮脸只改变视频显示，动捕继续分析原始画面；它复用现有姿态关键点，不额外运行独立人脸模型。可以分别调整整体大小、宽度、高度及上下左右位置。

**它仍是实验功能。** 首次定位前、快速运动、遮挡或人物丢失时可能漏遮，也不会遮住旁人的脸，不能保证逐帧完整覆盖。不满意可以直接关闭实验开关。

</details>

<details>
<summary><b>会录制或上传摄像头画面吗？</b></summary>

本应用在手机上进行姿态分析，不录制、保存或上传摄像头画面。摄像头只有在点击开启并授权后才启动；关闭摄像头或进入后台会释放镜头。

</details>

欢迎在 Issues 中描述问题或提出建议。反馈识别问题时，可说明手机型号、使用前置还是后置镜头、卡在哪个阶段，并附上必要的精简错误日志。

<details>
<summary><b>从源码构建</b></summary>

可用 Android Studio 打开项目；工程使用 Kotlin、CameraX 和 ML Kit。也提供 Windows 便携构建工具：

```powershell
python tools/prepare_build.py
python tools/prepare_relay.py
python tools/build.py '-Dorg.gradle.jvmargs=-Xmx3072m -Dfile.encoding=UTF-8 -XX:TieredStopAtLevel=1 -XX:ReservedCodeCacheSize=512m' testDebugUnitTest assembleDebug lintDebug
python tools/package_artifacts.py
```

工具位于项目内的 `.tools/`，不做全局安装；中继准备步骤用于后端集成测试。当前安装包使用开发签名，正式发布需自行配置发布签名。

</details>
